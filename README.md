# EcoSort AI – Smart Waste Classification & Management System

A web app where users upload a photo of waste, AI classifies it
(wet / dry / recyclable), recommends the correct bin, and tracks waste statistics.

## Features (planned)
- AI image detection
- Smart bin recommendation
- Waste dashboard and category-wise analytics
- History and manual correction
- Hostel waste insights

## Tech stack
HTML, CSS, JavaScript, TensorFlow.js, Teachable Machine, Chart.js
